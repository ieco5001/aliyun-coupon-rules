## 优惠券怎么用？预付费和按量付费是两套逻辑

包年包月这类预付费订单，在确认订单页面系统会按产品、支付类型、订单金额自动匹配可用券，你手动选一张。**单笔订单一次只能用一张券**；选了券但没支付，券会被未支付订单冻结，想换券就先把订单作废。

按量付费的资源不用手动操作，出账时系统自动抵扣：优先用快过期的券，到期时间相同就用余额多的；单张不够会自动接下一张代金券，直到抵完。开通自动续费时，系统也会按规则自动选券。

有一个坑提前说：**优惠券不能抵扣欠费**。先充值还清欠费，之后的按量账单才能正常用券。

## 通用优惠券不能用于哪些产品？先看清单再下单

这是被问得最多、也最容易踩坑的部分。通用优惠券有一份不适用清单，常见的产品包括：

- 域名、商标服务、工商财税
- CDN
- 短信服务、语音服务
- 云市场三方的全部商品
- 服务器硬件等实物类商品

还有一条很多人不知道：从2023年6月8日起，适用范围标注“全部商品适用”的优惠券，不再支持抵扣语音服务、短信服务和轻量消息队列（MNS）的消费。

有些活动页面写着券能用于CDN，和上面的清单冲突了？那是因为那张券属于“指定商品优惠券”，按活动规则走；通用券的排除清单是另一套规则。看券的类型，别只看“优惠券”三个字。

实用结论：买域名、CDN、短信包之前，先假设通用券帮不上忙，要么等活动指定的满减券，要么直接按活动价买。

## 优惠券用不了？按这个顺序排查

确认订单页看不到券，多半是下面某个原因：

1. 满减门槛没达到，订单金额不够
2. 产品在券的不适用清单里
3. 订单类型不符，比如券只支持新购，你下的是续费单
4. 优惠互斥，已经享受了其他活动折扣（学生专区、新人首购等）
5. 券过期或余额用完
6. 券被未支付订单冻结
7. 手机端和电脑端登录的不是同一个账号
8. 账号已持有50张有效券，新券领不了

顺带说下退回规则：支付前取消订单，券会退回；资源开通失败时，代金券和满减券能退，折扣券不退；域名和云虚拟主机下单失败后不退券。买域名前想清楚，别指望反悔。

## 几个高频问题

**一笔订单能用几张券？**
一张。多张叠用目前不支持，但一张券在有效期内可以反复使用，直到余额耗尽。

**优惠券能转给别人吗？**
个人账号之间不能转。企业用户可以开通企业账号中心，通过权益资产共享把券分给组织内账号或指定账号，随时可以取消共享。

**新老用户都能领吗？**
看具体券。云产品通用券一般新老用户都能领；大促满减券多面向新用户，官方领券中心里云服务器和轻量应用服务器的满减券则新老用户均可领取。一切以各活动页标注为准。

**券快过期了怎么办？**
按量付费账单会自动优先吃掉快过期的券。预付费订单的话，把近期要买的东西合并到一张订单里，结算时选它。实在用不完就让它过期，50张的持有上限也就腾出来了。
